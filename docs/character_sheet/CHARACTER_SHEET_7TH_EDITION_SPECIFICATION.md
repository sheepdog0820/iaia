# クトゥルフ神話TRPG 7版 キャラクターシート仕様書

**ステータス**: 正式サポート  
**最終更新**: 2026年7月25日

## 概要

タブレノの7版キャラクターシートは、クトゥルフ神話TRPG 7版のパーセンテージ能力値をそのまま保存する。共通の `CharacterSheet` は所有者、版、公開範囲などのレジストリ情報を保持し、基本情報、能力値、HP/MP/SAN/幸運、技能、装備、画像は7版専用の `CharacterSheet7th` と関連テーブルに保持する。7版固有の派生値は計算済みレスポンスとして提供する。

## 対応範囲

- 作成画面: `/accounts/character/create/7th/`
- 作成API: `/api/accounts/character-sheets/create_7th_edition/`
- 汎用作成API: `/api/accounts/character-sheets/`（`edition=7th`）
- 版別一覧API: `/api/accounts/character-sheets/by_edition/?edition=7th`
- 詳細/編集/一覧画面での7版表示
- セッション作成・テンプレート・シナリオ連携での7版選択
- CCFOLIA JSONインポート時の7版判定
- Google Sheets入出力での7版ステータス連携

## 能力値と派生値

### 能力値

- STR, CON, POW, DEX, APP, SIZ, INT, EDU は7版のパーセンテージ値として扱う。
- 画面の標準ダイス設定は `3D6×5`、SIZ/INT/EDU は `(2D6+6)×5`。
- DB上は既存互換のため `1..999` を許容する。UIと標準作成フローでは15..90相当を基本とする。

### 派生値

- 最大HP: `(CON + SIZ) // 10`
- 最大MP: `POW // 5`
- 初期SAN: `POW`
- 最大SAN: `99 - クトゥルフ神話技能`
- 幸運: 能力値とは独立して `3D6×5`（15..90）で決定する
- 回避初期値: `DEX // 2`
- 母国語初期値: `EDU`

### 幸運

- 新規作成画面では、幸運を能力値とは別に一度だけ `3D6×5` で生成する。
- 作成APIはトップレベルの `luck` を必須入力として受け取り、15から90までの5の倍数に制限する。
- 作成時の `luck` は `luck_starting`、`luck_current`、`luck_max` に同じ値を保存する。
- APIレスポンスでは、上記フィールドをそれぞれ `starting_luck`、`current_luck`、`max_luck` として返す。
- 既存の7版キャラクターを移行する場合は、従来仕様との互換性のためPOWを初期値・現在値・最大値に設定する。
- CCFOLIAインポートでは「幸運」または `LUCK` ステータスの現在値・最大値を保持し、未指定時は互換値としてPOWを使用する。
- Google Sheetsでは `LUCK` 列を現在値として入出力し、新規インポート時は初期値・現在値・最大値へ同じ値を設定する。新規作成で未指定の場合は互換値としてPOWを使用し、既存キャラクターの更新で未指定の場合は保存済みの幸運を維持する。
- 6版の幸運ロール `POW×5` は変更しない。

### ダメージボーナスとビルド

`STR + SIZ` を基準に以下を返す。

| 合計 | ダメージボーナス | ビルド |
| --- | --- | --- |
| 0-64 | -2 | -2 |
| 65-84 | -1 | -1 |
| 85-124 | +0 | 0 |
| 125-164 | +1D4 | 1 |
| 165-204 | +1D6 | 2 |
| 205-284 | +2D6 | 3 |
| 285-364 | +3D6 | 4 |
| 365-444 | +4D6 | 5 |
| 445+ | +5D6 | 6 |

### 移動率

- STRとDEXがどちらもSIZ未満: 7
- STRとDEXがどちらもSIZ超過: 9
- それ以外: 8
- 年齢40代から10歳ごとに1ずつ減少し、最低値は1。

## 技能ポイント

- 職業技能ポイント: 標準は `EDU × 4`
- 職業選択により `EDU×2 + APP/DEX/POW/STR/CON/SIZ×2` もUIで選択可能。
- 趣味技能ポイント: `INT × 2`
- 技能の現在値は `基本値 + 職業P + 趣味P + その他P` を基本とする。

## CCFOLIA出力

- 能力値は7版のパーセンテージ値をそのままパラメータへ出力し、`CC<={STR} 【STR】` 形式で判定する。
- 技能判定は `CC<=技能値 【技能名】` 形式で出力する。
- 幸運判定は `CC<={幸運} 【幸運】`、SAN判定はSANステータスを参照するコマンドとして出力する。
- ステータスにはHP、MP、SANに加えて、7版専用の現在幸運・最大幸運を出力する。
- `memo` には読み仮名だけをラベルなしで出力し、読み仮名が空の場合は空文字とする。
- 6版は `CCB` と能力値の `×5` 判定を維持し、7版のコマンドを混在させない。

## 作成API

`POST /api/accounts/character-sheets/create_7th_edition/` は、基本情報と能力値に加えて以下の7版固有入力を受け取る。

| フィールド | 必須 | 制約 | 保存先 |
| --- | --- | --- | --- |
| `luck` | 必須 | 15から90までの5の倍数 | `luck_starting`、`luck_current`、`luck_max` |

`luck` が未指定、空文字、整数以外、5の倍数以外、または範囲外の場合は `400 Bad Request` を返す。

汎用作成APIで `edition=7th` を指定した場合も同じ `luck` の必須条件と保存規則を適用する。作成中に技能・装備・画像の保存が失敗した場合は、キャラクター本体を含むDB更新をロールバックし、処理中にストレージへ保存済みの主画像・追加画像も削除する。

## APIレスポンス

`CharacterSheetSerializer` は7版キャラクターに `character_7th` を含める。

- `damage_bonus`
- `build`
- `move_rate`
- `dodge`
- `starting_luck`
- `current_luck`
- `max_luck`
- `occupation_points`
- `interest_points`

6版互換キーとして `character_6th` も返す。7版の場合は `character_6th: null`。

## 品質基準

- 7版作成API、独立した幸運値、派生値、技能ポイント、装備保存、一覧/詳細表示をテスト対象にする。
- 7版作成APIの正常系テストでは、有効なトップレベルの `luck` を送信する。
- `luck` の未指定、整数以外、5の倍数以外、14以下、91以上を異常系テストの対象にする。
- CCFOLIA出力は6版・7版それぞれの能力値、技能、SAN、幸運コマンドと読み仮名をテスト対象にする。
- 7版作成の異常系ではDBレコードに加え、ストレージへ保存済みの主画像・追加画像が残らないことを確認する。
- 6版の既存挙動を変更しない。
- 7版関連の「開発保留」文言はユーザー向け画面、ガイドライン、仕様書から除去する。
