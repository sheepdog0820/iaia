# Google Sheets出力先のURLと入力検証（2026-10-28）

PR #28の0f45ee78を基点に、既知cfc515ceの出力先修正を分離する。PR #28のマージ承認とは別の変更として扱う。

## 不具合と変更

シート名に`#`・`?`・`/`などが含まれると、出力先をURLへ直接埋め込む処理が、範囲をフラグメント・クエリ・別のパスとして扱う。スプレッドシートIDとA1範囲をそれぞれ独立したパス要素としてエンコードする。`valueInputOption=RAW`は既存どおりクエリで指定し、100行ずつの分割・開始行・値・進捗を維持する。

GoogleのID文字種を独自に限定せず、不正な型・空値・単独の`.`/`..`・内部の制御文字・UTF-8に変換できない値を拒否する。APIの空欄・null・空白だけのIDは従来のプレビューとして扱う。不正な出力先はジョブ作成前に日本語の400応答とし、既存ジョブを処理するワーカーもトークン更新・送信の前に検証する。

公式の[values.update API](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/update)のパス引数とクエリの区別に従う。権限スコープやGoogle側のシート名・IDの許容範囲を変更するものではない。
