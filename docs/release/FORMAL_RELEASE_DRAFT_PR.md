# 正式公開に向けた無料機能の拡大と課金・認証・秘匿情報保護の修正

Base: main / Head: codex/delegated-workflow-rules / Draft: true

シナリオの作成編集・CCFOLIAインポート・作成済みセッションの関連シナリオ変更を無料で利用できるようにし、キャラクター画像を全プラン共通で5枚までに統一します。既存の超過画像は保持し、基本情報の編集・画像削除を維持します。有料機能は背景透過に限定し、承認済みの月額480円・年額4,800円と機能比較表を揃えます。GM・所有者・閲覧権限は引き続き検査します。

有料プランと外部連携を含む正式公開に必要な不具合修正と検証資料をまとめます。公開条件は未達で、マージ・リリース可能とは判定していません。

主な修正:

- Stripe SDKのイベント形式、契約期間、WebhookのDB障害時の再処理と、Google/X/Discord認証の本人照合・登録競合・停止済み利用者の拒否を整備。
- Google追加連携のトークン応答から権限と資格情報を保存し、通常ログインや別ユーザーの選択による上書きを防止。ユーザーごとに1件の有効なGoogle連携資格情報を、権限と一緒に更新。
- 秘匿添付と画像の取得時認可、旧URLの保護、削除失敗時の参照保持、ログ内のトークン・機密情報の保護を追加。CloudFront迂回防止の構成案は未適用。
- ホーム、履歴、招待、カレンダー、参加者・キャラクター選択欄の名前や説明を文字として表示し、HTMLの挿入を防止。ゲスト表示とキャラクターシートURLの扱いを修正。
- 技能の一括保存、既存データ入りPostgreSQLの移行、日程投票の時間帯・キャッシュ、招待への同時参加、ゲスト参加と登録後の引き継ぎを修正。ハンドアウトのテンプレート作成では、一覧に示した本文全体を保存。
- Bootstrap・FullCalendar・Font Awesomeを同梱し、背景透過はU2netを明示的に使用。外部出力時の権限再確認、通信タイムアウト、一覧取得と運用検査を整備。
- ブラウザ検証用の隔離DB準備と初回失敗のトレース保持を追加し、受け入れ条件・監視・復旧・ロールバックの資料を整備。
