# 無料機能の拡大と課金・認証・秘匿情報保護の修正

Base: main / Head: codex/delegated-workflow-rules / Draft: true

シナリオ作成・編集、CCFOLIAインポート、作成済みセッションの関連シナリオ変更を無料にします。キャラクター画像は全プラン共通で5枚までとし、既存の超過画像の保持・編集・削除を維持します。有料機能は背景透過に限定し、承認済みの月額480円・年額4,800円に表示を揃えます。GM・所有者・閲覧権限の制限は維持します。

## 変更内容

- 課金Webhookのイベント形式・契約期間・DB障害時の再処理を修正。Google/X/Discord認証で本人照合・登録競合・停止済みユーザーを検査。
- Google追加連携の応答から許可された権限と資格情報を保存。通常ログインや別ユーザーの選択による上書きを防止。
- 秘匿添付・画像の認可、旧URL保護、削除失敗時の参照保持、ログの機密情報保護を整備。
- 主要画面のHTML挿入防止、技能の一括保存、日程投票・招待への同時参加、ゲストの引き継ぎ、履歴キャッシュ、読み込み中クリックを修正。
- フロントエンド資産の同梱、背景透過U2net、外部通信のタイムアウト、Redis証明書検証を整備。
- 旧移行のストレージ削除失敗を秘匿情報なしで警告。開発画像生成の予期しない例外を伝播。Banditの確認済み誤検知には対象行・ルール限定の根拠を記載。
- codex/**へのpushでも既存CI全5ジョブを実行し、BanditをAPI・supportを含む6アプリへ拡大。

## 影響・復旧・公開前の残作業

DB移行ファイルとインフラ構成案を含むが、共有DBへの適用、AWS反映、Secrets・権限変更、実データ操作は実施していない。旧0041の変更は警告追加であり、移行順序・スキーマ・継続動作を維持し、適用済み環境での再実行はしない。既存ストレージに残った可能性があるファイルは別途照合する。

実Stripeの契約・更新・解約・失効・再送、実Googleの保存・同期、外部配送、非同期実行基盤、S3/CDN保護、性能・復旧基準の実証は公開前の残作業。背景透過の利用・保存条件、法務表示、公開日の確定も必要。全条件は[公開受け入れ条件](FORMAL_RELEASE_ACCEPTANCE_MATRIX.md)で管理する。マージは正式公開完了を意味しない。

未反映の変更は作業ブランチのrevertで戻せる。実環境へ反映する際は[配備準備資料](AWS_PRE_FORMAL_RELEASE_VALIDATION_PLAN.md)に従い、対象・DB移行・復旧手順と承認を確認する。
