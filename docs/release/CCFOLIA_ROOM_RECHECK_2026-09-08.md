# ココフォリア実ルームの接続復旧と保存状態確認

2026-09-08、ユーザー指定のChromeで、承認済みの6版・7版テストルームへ接続できた。以前の「Chromeに接続できない」という阻害要因は今回解消した。ルームURL・IDはこの文書に記録しない。

## 読み取り結果

画面上のココフォリアは1.37.3、DicebotはBCDice 3.17.0。各ルームの既存「タブレノ連携検証 6th 20260906」「タブレノ連携検証 7th 20260906」を一覧と編集画面で確認した。

| 項目 | 6版 | 7版 |
| --- | --- | --- |
| HP / MP | 9/11、12/14 | 9/11、12/14 |
| SAN | 65/65 | 65/65 |
| 幸運のステータス | なし | 55/60 |
| STR / CON / POW / DEX | 12 / 10 / 14 / 13 | 60 / 50 / 70 / 65 |
| APP / SIZ / INT / EDU | 11 / 12 / 15 / 16 | 55 / 60 / 75 / 80 |
| DB / イニシアティブ | 0 / 13 | +0 / 65 |
| 技能・能力値パレット | CCBの目星65・能力値×5等 | CCの目星65・能力値・現在幸運参照等 |

これらは以前取り込んだテスト駒の保存内容であり、最新候補を新しく取り込んだ証拠ではない。SAN最大値の元データとの仕様照合は従来の残条件を維持する。画像・差分は未設定で、受け取り側の実画像検証は未完了。

## 実ダイス確認の準備

既存パレットから、次の各3コマンドの実行を準備した。計6件の結果がルームチャットに残るため、送信の明示的な許可を質問中。質問したことを許可済みと扱わない。

| 対象 | 送信候補 |
| --- | --- |
| 6版 | `CCB<=65 【目星】`、`CCB<={STR}*5 【STR × 5】`、`1D3+{DB} 【こぶしダメージ】` |
| 7版 | `CC<=65 【目星】`、`CC<={幸運} 【幸運】`、`1D3+{DB} 【近接戦闘ダメージ】` |

送信許可後は、それぞれのルームで対象キャラクターを選択し直し、名前とパレットの有効状態を確認する。今回7版ルームを開いたとき、発言者名は直前の6版キャラクター名を表示し、パレットが無効だった。正しい駒を選ばずに送信しない。

期待する検証は、ダイスが解釈されること、6版STRの目標値60・7版幸運の目標値55・DB参照が解決すること、結果が対象テストキャラクター名で残ること。出目の成功/失敗は試験の合否ではない。

編集画面は閉じ、両ルームをChromeに残した。キャラクターの数値・画像・設定、チャットログ、権限、ルーム構成は変更していない。チャット送信・画像アップロードは未実施。タブレノ側の共有DB・Secrets・費用への変更もない。
