# 背景ジョブの完了とタイムアウト競合（2026-10-28）

main 945441ffを基点に、既知c0b5380bから完了/タイムアウト処理と回帰テスト、CIのPostgreSQL対象追加を分離する。背景透過の診断初期化防止PR #22、版情報保持PR #21とは独立した候補である。

## 不具合と利用者への影響

タイムアウトや削除の後に推論が完了すると、古いワーカーが結果画像を保存したり、失敗状態を完了で上書きしたりする。古いタイムアウト判定も、先に完了した処理や新しく開始したワーカーの状態を上書きする。未修正の状態を隔離PostgreSQLで再現し、9失敗・6成功を確認した。

推論と入力読み取りは短い処理単位に分け、推論中にDBロックを保持しない。完了保存とタイムアウト判定では対象行をロックして最新状態を再取得し、既に確定した状態を尊重する。削除済みの行を復活させず、遅い結果を公開せず、入力ファイルを推論前に閉じる。既存の結果保存失敗・PNG検証・ファイル名処理と権限/利用制限は維持する。

## 境界と残作業

DBスキーマ・依存・料金・保存期間を変更しない。実データ、共有DB、AWS/ECS/S3、Secrets/権限、費用、外部通知は変更しない。ストレージや推論は合成画像と一時領域で検証しており、実運用の同時負荷・復旧やS3障害時の完全な原子性を保証しない。

ワーカー起動応答と実処理の進行、結果受信と保存期間処理、SDKの再試行後の起動結果不確定は別の既知候補として継続する。main追加マージは具体的な最終headと検証結果で別途承認を確認する。復旧はrevert PRだが、古い状態の上書きが再発するため、修正版への前進を優先する。[正式公開条件](FORMAL_RELEASE_ACCEPTANCE_MATRIX.md)・OS50指摘・Twisted RC2とNo-Goを維持する。
