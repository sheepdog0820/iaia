## 不具合と修正方針

ログイン済みユーザーの古い属性を最初に確認するだけでは、画像検査中に有料権限が失効した場合でもジョブを作成する。検査中のユーザー削除は500となる。ジョブ作成に使うユーザー行をロックして最新状態を再取得し、拒否時にはジョブ・入力ファイル・起動依頼を作らず、既存ジョブの片付けもしない。

有料機能の範囲や料金は変えず、staff/superuserも既存の有料条件を満たす必要がある。認可済みの作成後に権限が失効した場合、既存ジョブを遡って中断する方針は追加しない。新しい拒否表示は日本語とする。
