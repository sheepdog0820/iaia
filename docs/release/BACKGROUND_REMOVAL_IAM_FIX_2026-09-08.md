# 開発環境の背景透過起動権限修正

## 問題と承認範囲

ユーザーの「背景透過の権限修正を進めてください」を、提示済みの実行定義3の起動許可追加とWeb参照変更への承認として実施した。

修正前のWeb定義42は `tableno-aws-pre-background-removal:2` を指定していたが、Webロール `tableno-aws-pre-ecs-task` の起動用inline policyは定義1のみを許可していた。他のinline policyにECS起動許可はなく、attached policyは0件。定義2を起動するための許可が欠けていた。既存ユーザーの失敗操作や画像は再実行していない。

## 修正

- 既存のIAM文をすべて保持し、定義3の完全なARNだけを `ecs:RunTask` で許可する文を追加。ワイルドカードやPassRole対象の追加なし。適用直前の元ポリシー一致、適用後の読み戻し一致を確認した。
- Web定義42の `BACKGROUND_REMOVAL_TASK_DEFINITION` だけを定義3へ変更したWeb定義43を登録。他の環境変数・Secrets参照・イメージ・ロール・CPU・メモリ・ネットワーク等は一致することを比較した。
- 背景透過定義3は既に準備済みのmain `14ac4746` のdigestを使用する。Webはフォント修正済み `fa09731c` を保持する。両者の背景透過処理コードは同一。CPU1・メモリ2GB、処理要求ごとの単発実行を維持する。
- DB移行・静的収集・CloudFront変更は不要。常時稼働台数を増やさない。

## 検証

Web定義43の単発検証タスクから、アプリと同じ `start_background_removal_task` を実行した。AWS管理者の資格情報ではなく、実際のWebタスクロールで定義3の起動に成功した。

テストは、この検証専用の無効アカウント（パスワード利用不可・メール空欄）と合成人物画像を使用する。通常の永続ジョブ、実S3入力、背景透過コマンド、実S3出力を通す。既存利用者の画像や利用回数を変更しない。ブラウザからの有料会員判定・アップロードUI全体の試験とは区別する。

実処理は成功した。

- Webロールによる検証タスク `be8961389cf64270882b2427f5ea4bba` はSTOPPED/終了0。
- このタスクがアプリの起動関数から起動した背景透過タスク `af9b7f95a63b45ebb5a8ee62b07be377` は定義3、STOPPED/終了0。起動22:16:40 JST、停止22:18:28 JST（停止処理を含む約108秒）。この1件を性能保証とは扱わない。
- ジョブ `55c288e5-eb4f-4322-8a28-2fc7de10e431` はpending→running→completed。384×512のPNG、16,993バイト、アルファ最小0/最大255、完全透明132,172ピクセルを確認。元画像の削除と出力画像のS3取得も成功した。
- 作成したジョブと無効アカウントを削除し、アカウントの残存なしを確認。入力・出力それぞれのS3バージョンと削除マーカー計4件を、検証開始後の作成時刻・完全一致キー・VersionIdを確認して削除し、残存なしを確認した。
- 実処理成功後にWeb定義43への切り替えを完了。desired/running=1/1、rollout COMPLETED、旧定義42は稼働0。新Webタスク `7a277a8b135a4f619bfec47b753a3a18` はHEALTHYで、フォント修正済みイメージのdigest保持を確認。HTTPS readinessはDB/cacheともok。IAMも最後に読み戻して適用内容と一致した。

開発環境では、権限による起動不整合を解消し、背景透過処理の実行成功を確認できた。ブラウザからのプレミアム判定・アップロードUI全体は今回再検証していない。プレミアム条件、日次制限、既存ユーザーの利用回数は変更していない。関連するフォント修正のCIは別途進行中であり、今回のAWS実行確認をCI全体成功とは扱わない。

## 復旧

Web定義42に戻し、IAMポリシーを保存済み元ポリシーへ戻すことは可能だが、元の起動不整合も戻る。元ポリシー・各定義・実行証跡はGit管理外の `tmp/background-fix-20260908/` に保存。復旧時も他の担当者の追加変更がないことを比較する。

TerraformはWeb参照・IAM許可の両方で同じ背景透過定義ARNを使用する記述になっており、今回はソース変更不要。今後CLIで背景透過定義を更新する場合は、Web参照だけでなくIAMの許可対象も揃えて確認する。
