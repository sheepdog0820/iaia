# キャラクター一覧のHTML保護

キャラクター名、職業、APIエラー文を動的HTMLへ直接挿入していた経路を修正した。名前のalt属性と表示本文、職業、エラー文、画像URL属性、版表示をHTMLエスケープする。入力値の保存内容と既存の日本語文言は変更しない。

## 検証

`tests/e2e/flows/character-list-security.spec.ts`でタグと引用符、onerror属性を含む文字列をAPI応答として模擬した。修正前は名前・職業とエラー文の2件が失敗し、HTMLとして解釈されることを確認した。

修正後のcheckoutをポート8001で起動し、Chromium・Firefox・WebKitの計6件が成功した。元の文字列の表示、alt属性の値、攻撃用img要素0、イベント実行0を確認した。既存8000番サーバーは旧テンプレートを返したため、その実行結果を修正後の検証には使用していない。

DBへ攻撃文字列は保存していない。実AWSの確認や、保存から別利用者への表示までの全経路検証ではない。CI全体と配布物の検証は未完了。

## 残る範囲

詳細画面の成長記録と成長サマリーには、scenario_name、gm_name、special_rewards、notes、skill_name等の未エスケープ挿入が残る。別の修正と回帰検証が必要であり、キャラクター画面全体の監査完了とはしない。
