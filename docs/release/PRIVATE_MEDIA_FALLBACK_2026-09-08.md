# DEBUG環境の非公開作業ファイル配信を拒否

2026-09-08。背景透過の入力・結果ファイルと廃止済みセッションテンプレートの残存ファイルが、DEBUG=Trueの `/media/` 静的配信から取得できる問題を隔離ファイルで再現した。実ユーザーデータや共有環境のファイルにはアクセスしていない。

## 修正と検証

`tableno/media_views.py` で正規化後の `background_removal/` と `session_template_images/` を404にする。透過結果は既存の所有者確認付きステータスAPIから取得し、静的配信に依存しない。廃止済みテンプレート機能は復活させず、ファイル削除も行わない。

3種類の実ファイル×通常/迂回パス×DEBUG有無の12条件を検査。修正前はDEBUG時の6条件が200となり失敗、修正後は全条件が404。通常キャラクター画像のDEBUG配信が200で内容一致する対照試験も成功した。

背景透過ジョブ・問い合わせ添付・セッション画像・シナリオ画像の回帰を含む59テストが成功。背景透過処理の外部実行は既存テストのモックを利用し、新しい推論モデル取得やAWSジョブ起動はしていない。限定カバレッジ試験では追加した条件の両分岐と拒否文を実行済み。既存の別配信経路を対象外としたこの試験だけではモジュール全体は71%であり、全体100%とは扱わない。

Black・isort・Flake8・差分検査を通過。認可付き経路を迂回しないこと、通常配信を維持すること、ユーザー向け文言の追加がないことを自己レビューし、今回の変更に未修正の指摘はない。

## 影響と残条件

実環境のDEBUG設定を変更せず、DEBUG=Falseでは従来どおりこれらの直URLは404となる。DB・実データ・Secrets・権限付与・AWS・費用の変更はない。実環境のCDN直アクセスは別経路のため、[S3拒否設定の適用](BACKGROUND_REMOVAL_CDN_PROTECTION_2026-09-08.md)が引き続き必要。今回のソース修正だけで実S3の保護完了とはしない。

修正は作業ブランチでrevert可能。ただしDEBUG環境の非公開ファイル取得を再び許すため、不具合時も直接配信を復旧手段にせず、必要な認可付き経路を修正する。変更後の全体CI・共有環境検証は別途確認する。
