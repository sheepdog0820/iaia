# 正式公開の性能・復旧基準の決定

2026-09-08、ユーザーが次の基準を採用した。合格基準の確定であり、達成済みの記録や本番反映の承認ではない。

| 項目 | 確定した基準 | 判定上の注意 |
| --- | --- | --- |
| 利用規模 | 登録100人・同時利用10人 | 代表データ量と操作の配分を試験条件に記録する |
| 通常操作の応答 | 95%が3秒以内 | 一覧・保存など。背景透過処理は別枠で測定する |
| エラー | 試験中の予期しないエラー0件 | 正常な入力検証・権限拒否は区別する |
| 復旧点（RPO） | 24時間以内 | 障害時に直近24時間分の変更を失う可能性を許容する目標。DBとファイルの整合が必要 |
| 復旧時間（RTO） | 復旧対応開始から4時間以内 | 障害発生からの時間や24時間対応を約束するものではない。検知・対応開始までの運用条件は別途必要 |

既存の単発ローカル測定を、この決定だけで合格へ変更しない。通常操作の反復・本番相当条件、代表データ量、失敗・外れ値、復旧の起点と完了条件を記録して検証する。追加費用を伴う構成変更は見積もりを提示する。
