## 人間の判断に使う現行案

以下は `tableno/legal_views.py` の表示定義を転記した比較であり、正式な料金承認や全APIの権限制御の証拠ではない。

| 項目 | 無料 | 有料の現行案 |
| --- | --- | --- |
| 料金 | 無料 | 月額480円 / 年額4,800円（未承認） |
| キャラクター・セッション管理 | 利用可 | 利用可 |
| シナリオアーカイブ | 利用不可 | 利用可 |
| CCFOLIAインポート | 利用不可 | 利用可 |
| 支払い方法・解約・請求履歴 | 対象外 | Stripe Customer Portal |
| 運営発行コード | 入力可 | 期限付き/無期限の権限付与。課金契約とは別 |

画像上限等の追加の機能差は実装・仕様との照合が残る。シナリオ画像の既定上限は無料/有料とも1枚5 MiB・1回10枚（環境設定で変更可能）。また、有料制限はアーカイブ画面にあり、シナリオAPI自体はログイン/可視性/所有権で制御される。「シナリオ管理全体が有料」という販売条件とは一致しないため、画面限定の意図かAPIを含む制限かを公開前に確定する。比較表の完成前に表示だけを販売条件として確定しない。返金・保存・事業者表示の方針は別途確認する。

性能試験の仮条件は登録100人・同時10人。ユーザー回答待ちであり、未承認の試験設計案として扱う。データ量、シナリオ比率、95パーセンタイル応答時間、許容エラー率、アップロード容量、RPO/RTOの具体値を決めてから合否を判定する。測定前に合格基準を緩めて成功扱いにしない。

## 実環境検証を開始するための準備

- GitHub: pushは可能、PR作成連携は403。PR作成可能な接続が必要。mainへのマージは別承認。
- Stripe: 連携の再認証が必要。再認証後まず読み取りでテストモード・Price・Webhookを照合し、必要な変更だけを一覧化する。秘密鍵を会話へ貼らない。
- AWS開発環境: 2026-09-05の再確認でECS desired/runningは1/1、ヘルス200へ変化。このタスクから起動していない。稼働版との差分にはDB移行があり、[配備準備計画](AWS_PRE_FORMAL_RELEASE_VALIDATION_PLAN.md)で対象SHA・移行・復旧・費用の未完了項目を整理した。稼働中サービスを勝手に停止せず、配備前に具体案を揃えて承認を求める。
- 外部の検証対象: Googleの専用カレンダー/シート、Discordの専用通知先、ICS購読先、CCFOLIAの専用ルームを定める。一般利用者へ試験通知しない。

上記の接続・判断待ちだけで全作業を停止しない。Codexは権限のある範囲で固定依存関係検証、通常ユーザーの検証不足、性能試験設計、復旧計画、残るコード監査を進める。
