# 成長記録・成長サマリーの表示安全性

## 変更

- キャラクター詳細の成長記録で、シナリオ名・GM名・報酬・メモ・技能名（および日付）を既存の `escapeHtml` でエスケープする。
- 成長サマリーの技能名にも同じ処理を適用する。
- HTMLを入力しても文字列として表示し、イベントハンドラーを含む要素を生成しない。数値・IDは既存の型付きAPI契約を維持する。
- 技能選択肢は既に `textContent` を使用しており、変更不要。

## 検証

- Playwrightで使い捨てキャラクターを作成し、成長APIのみをモック。finallyでキャラクターを削除する。
- 修正前はChromiumの文字列表示検証が失敗（RED）。ログイン先・fixture不足による準備段階の失敗とは区別する。
- テンプレートをキャッシュしていた専用サーバーを再起動後、成長記録・サマリーと既存一覧表示のテストがChromium / Firefox / WebKitで計9件成功（17.6秒）。
- タグの文字列表示、画像要素が生成されないこと、スクリプト未実行、成長数値の表示とモーダル開閉を検証。
- 関連静的テスト `tests.unit.test_character_create_ui_static` 46件成功。差分・UTF-8/LF検査成功、自己レビューで本修正範囲に追加指摘なし。
- 日本語UI文言は変更しない。既存入力値の表示以外の動作・権限・DBスキーマは変更しない。
