# 2026-09-06に確定した無料・有料範囲の反映

ユーザー決定は[料金・有料機能の確定資料](FORMAL_RELEASE_PLAN_DECISIONS.md)の冒頭を基準とする。正式公開全体の合格や本番反映を意味しない。

## KP向け基本機能の無料化

- シナリオアーカイブをログインユーザー全員に開放し、ナビゲーションとホームの作成導線を表示する。シナリオ作成・編集APIに有料制限はもともとなく、可視性・所有権の検査を維持する。
- CCFOLIAインポートの有料制限をAPIと画面から解除する。通常登録ユーザーのキャラクターとして保存し、認証・入力検証を維持する。
- 作成済みセッションの関連シナリオ差し替えを無料化する。KP/GM・参照先の可視性の検査を維持する。
- 課金管理画面・機能比較表を無料範囲に合わせ、有料機能は画像の背景透過であることを表示する。
- 契約ライフサイクルの検証を更新し、無料・支払失敗・解約後もアーカイブとインポートを利用でき、背景透過の有料判定は維持されることを確認する。

変更前の5ケースが失敗した後、隔離SQLiteで関連168件・13 subtestsが成功（9 warnings）。証跡: tmp/free-features-red.log、tmp/free-features-green.log。背景透過の画像入力を伴う処理テスト、非GM・他人の秘匿情報に関する既存検査を含む。実Stripeイベントや実外部サービスの検証ではない。

追加監査でセッション詳細の通常経路と共有経路にも有料の表示条件が残っていたため、両方をGMの秘匿情報管理権限に揃えた。無料GMの選択欄表示と非GM所有者の変更不可を検証し、関連35件・4 subtestsが成功（9 warnings、tmp/free-scenario-edit-final.log）。変更前と片側だけ修正した段階の失敗は同-red.log、同-green.logに保持する。

DB移行・実データ削除・秘密情報・費用変更なし。本番未反映。復旧は該当コミットの差分を戻す操作で、無料化後に作られたデータを削除しない。

## 全プラン共通の画像5枚上限

- 作成フォーム・作成API・追加画像API・6版/7版のJavaScript上限を5枚に統一。機能比較表にも共通上限を表示する。
- 旧上限で6枚以上保存したキャラクターは維持し、名前・画像の順序の編集と削除を許可する。5枚時は追加を拒否し、4枚まで減らせば1枚追加できる。上限超過時の既存画像の編集に枚数検査を適用しないが、画像の形式・容量・所有権の検査は維持する。
- 変更前3ケースの失敗を確認。関連81件・16 subtestsが成功（15 warnings）。旧総容量テストは8枚の入力を前提にしていたため、5枚以内で推定総容量30 MiBを超える入力へ更新し、容量制限の検証を維持した。証跡: tmp/shared-image-limit-red.log、tmp/shared-image-limit-green.log（80成功/1失敗）、tmp/shared-image-limit-final.log（81成功）。
