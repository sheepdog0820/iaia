# 正式公開の料金・有料機能の確定資料

## 2026-09-06のユーザー決定（以下の旧推奨案に優先）

- P01: シナリオのアーカイブ・作成・編集を無料で利用可能にする。ログイン、所有権、参加者の閲覧権限は維持する。
- P02: 有料の利用機能は画像の背景透過に限定する。CCFOLIAインポートも無料化する。画像枚数は無料・有料とも1キャラクター5枚とする（追加質問への回答）。画像情報の表示項目追加を有料特典にしない。
- P03: 月額480円・年額4,800円を採用する。実Stripe設定変更や本番反映の承認とは区別する。
- P04: 無料範囲の拡大に合わせ、失効時に基本機能を制限しない。既存データを削除しない。既存画像が5枚を超える場合も保持・基本情報編集・画像削除を許可し、新規追加は5枚未満になってから許可する実装方針。
- P05: 作成済みセッションの関連シナリオ差し替えも無料にする（追加質問への回答）。GM・シナリオ閲覧権限の検査は維持する。

この決定は仕様の確定であり、実装・検証完了の記録ではない。背景透過の回数・容量・保持条件、税表示・事業者情報、実サービス検証等の公開前確認は継続する。

以下は決定前の調査・比較と提案の履歴であり、「回答待ち」「未承認」は当時の状態を表す。

調査日: 2026-09-05。確認元: `c50b5fc6` のコード・既存テスト。以下は実装の棚卸しであり、販売条件の承認記録ではない。公開画面・API制限・料金設定は、この資料の作成では変更していない。

## 管理者と一般契約者の違い

`has_premium_access` は `is_premium`、staff、superuserのいずれかでTrueとなる。一方、画像枚数と背景透過の新規処理は `is_premium` 自体を使う。したがって、管理者の操作結果だけでは一般の有料契約者の受け入れ証拠にならない。運営用の例外を販売上の特典として扱わない。

## 正式公開に向けた推奨案（未承認）

2026-09-05、a205e814時点で公開画面とAPIの制限差を再確認した。次の案をP01〜P05の一つの選択肢として提示する。承認記録ではなく、料金・規約の公表や実Stripe設定の変更も行っていない。

| ID | 推奨する決定 | 承認後に揃える実装・検証 |
| --- | --- | --- |
| P01 | シナリオの作成・編集はアーカイブ画面とAPIの両方で有料に統一する。招待されたセッションへの参加と、権限を持つ参加者が必要情報を読む操作は無料のまま | 通常の無料/有料利用者で画面・APIの一致と参加者の閲覧維持を検証 |
| P02 | 比較表に画像2枚→10枚、背景透過、CCFOLIAインポート、シナリオ作成編集、作成済みセッションの関連シナリオ変更を掲載する。背景透過は現行の1日10回・同時1件・失敗も回数に含む・結果24時間/ジョブ7日の条件を明記する | 比較表と制限・日本語エラー・保持/削除処理の一致を確認。上記以外の容量/入力制限は既存仕様を維持 |
| P03 | 現行表示案の月額480円・年額4,800円を正式な料金として採用する | 販売表示・実Stripe Price・月額/年額Checkout・期間末解約を照合。税の表示や事業者表示は別途の公開前確認を維持 |
| P04 | 有料失効後も既存データを自動削除せず、閲覧と有料機能に依存しない基本情報の編集を維持する。無料枠を超えた新規画像追加、背景透過の新規実行、有料の作成編集等は拒否する。既存画像の削除は可能とする | 無料枠超過によって名前等の基本情報まで編集不能にならないことを検証。有料機能そのものの操作は無料へ開放しない |
| P05 | セッション作成時の初回シナリオ関連付けは無料、作成後の関連先変更は有料という現行条件を採用する。参照先の可視性とGM権限は従来どおり必須 | 作成と更新の境界、同じ関連先の再送、非GM・参照権限のないシナリオの拒否を検証 |

推奨理由は、現行の料金表示と主要な無料参加導線を保ちながら、シナリオ作成編集の画面/APIの制限差を解消し、解約後のデータ保持と操作制限を説明可能にするため。P01のAPI制限追加とP04の基本編集維持は、現状から利用者への約束が変わるため人間の決定が必要になる。

この案が承認されても、実課金・実Stripe設定・共有環境の変更・本番配備・正式告知をまとめて承認したものとは扱わない。これらは対象と影響を具体化した別の実行境界として維持する。
