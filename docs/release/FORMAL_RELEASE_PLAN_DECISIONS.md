## 決定が必要な事項

| ID | 決めること | 現状と具体的な選択肢 | 状態 |
| --- | --- | --- | --- |
| P01 | シナリオを有料とする範囲 | A: アーカイブ画面・作成編集APIを有料に統一。B: 画面のみ有料の現状を維持し、販売説明もその範囲に限定。どちらも招待されたセッションへの参加・必要情報の閲覧を無料で維持する案 | ユーザーに質問済み、回答待ち |
| P02 | 有料機能として表示する項目 | 実装済みの画像2→10枚、背景透過、関連シナリオ変更を比較表に追加する案。背景透過は失敗を含む回数計算・日次枠・保存期間も説明対象 | 未確定 |
| P03 | 料金 | 月額480円・年額4,800円を正式採用するか。機能差を確定してから、画面と実Priceを一致させる | 先の質問への回答待ち |
| P04 | 有料失効時の既存データ操作 | 既存データの保持と、新規追加・既存編集の制限を分けて決める。現在の画像serializerは既存枚数が無料上限を超えていると更新も拒否し得る。保持データの一括削除は今回行わない | 未確定 |
| P05 | 初回のシナリオ関連付け | 初回は無料、変更は有料という現状を採用するか。P01の決定と合わせて整合させる | 未確定 |

これらは事業・利用権限の決定であり、Codexが未回答を承認扱いしてAPI制限や販売条件を変更しない。決定後に、画面、API、権限テスト、料金表示、運用説明をまとめて一致させる。

## 管理者と一般契約者の違い

`has_premium_access` は `is_premium`、staff、superuserのいずれかでTrueとなる。一方、画像枚数と背景透過の新規処理は `is_premium` 自体を使う。したがって、管理者の操作結果だけでは一般の有料契約者の受け入れ証拠にならない。運営用の例外を販売上の特典として扱わない。
